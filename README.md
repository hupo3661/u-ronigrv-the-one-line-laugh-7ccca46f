One funny line for make.fun's "The One-Line Laugh" bounty: a single sentence of at most 200 characters that lands a surprise at the end — a smart speaker asked for something relaxing answers by reading unread emails out loud. `main.py` writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
